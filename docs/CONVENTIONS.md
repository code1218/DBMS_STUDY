# SQL 작성 규칙 (과정 공통)

교안·정답·강사 시연 코드가 모두 이 규칙을 따릅니다. 학생에게도 1챕터에서 같은 규칙을 안내합니다. 실무 코드 리뷰에서 가장 먼저 지적받는 것들입니다.

## 1. 대소문자
- SQL 예약어는 **대문자**: `SELECT`, `FROM`, `WHERE`, `JOIN`, `AND`, `NULL`, `TRUE`
- 테이블·열·별칭은 **소문자 snake_case**: `order_items`, `delivery_fee`, `total_amount`
- 함수명은 대문자: `COUNT()`, `DATE_FORMAT()`

## 2. 줄바꿈과 들여쓰기
절(clause)마다 줄을 바꾸고, 열이 여러 개면 한 줄에 하나씩, 들여쓰기는 공백 4칸.

```sql
SELECT name,
    category,
    min_order_amount
FROM restaurants
WHERE district = '부산진구'
    AND is_open = TRUE
ORDER BY min_order_amount;
```

> 교안에서는 지면을 아끼려고 짧은 쿼리는 한 줄로 쓰기도 합니다. 세 줄을 넘으면 위 형식으로 씁니다.

## 3. 별칭(AS)
- 열 별칭은 `AS`를 생략하지 않습니다: `price * 2 AS double_price`
- 결과 열 이름은 **영문 snake_case**를 기본으로 합니다. 한글 별칭(`AS 가게명`)도 동작하지만, 애플리케이션(Java·Python)에서 결과를 받을 때 불편해 실무에서는 피합니다. 교안에서 결과를 읽기 쉽게 보여줄 때만 한글 별칭을 백틱으로 씁니다: ``AS `가게명` ``
- 테이블 별칭은 의미 있는 1~2글자: `orders o`, `order_items oi`, `restaurants r`

## 4. 문자열·날짜 리터럴
- 문자열과 날짜는 **작은따옴표**: `'부산진구'`, `'2026-06-30'`
- 큰따옴표는 쓰지 않습니다 (표준 SQL에서 큰따옴표는 식별자용)
- 날짜는 `'YYYY-MM-DD'`, 일시는 `'YYYY-MM-DD HH:MM:SS'`

## 5. 데이터베이스 이름
- 챕터마다 새 DB: `hanip_delivery01`, `hanip_delivery02`, … (두 자리 번호)
- 배포 `.sql` 파일은 첫 실행 문장으로 해당 챕터 DB를 `USE`합니다.

## 6. 기준일
- 데이터의 "오늘"은 **2026-06-30**, 스냅숏 시각은 **2026-06-30 19:00:00**
- 날짜 계산은 `'2026-06-30'`을 직접 쓰거나 변수로 둡니다: `SET @today = '2026-06-30';`
- `NOW()`, `CURDATE()`는 개념 설명용으로만 씁니다. 수업 날짜마다 결과가 달라지기 때문입니다.

## 7. 금지·주의
| 하지 말 것 | 이유 | 대신 |
|---|---|---|
| `SELECT *` (실무 코드) | 열이 추가되면 결과가 바뀜, 불필요한 전송 | 필요한 열만 나열. 단, 탐색용으로는 OK |
| `= NULL` | 항상 결과 없음 | `IS NULL` |
| `WHERE` 없는 `UPDATE`/`DELETE` | 전체 행 변경 | 먼저 같은 조건으로 `SELECT`해서 대상 확인 |
| 열 이름 없는 `INSERT INTO t VALUES (...)` | 열 순서가 바뀌면 조용히 잘못 들어감 | `INSERT INTO t (a, b) VALUES (...)` |
| `ORDER BY 1, 2` (열 번호) | 열 순서 바뀌면 의미가 바뀜 | 열 이름이나 별칭 |

## 8. 파일 머리말
배포하는 `.sql` 파일은 첫 줄에 용도와 실행 전제를 적습니다.

```sql
-- =============================================================
--  Ch02 SELECT 기본 — 강사 시연 스크립트
--  전제: 이 챕터의 setup.sql 실행 완료 (hanip_delivery02)
-- =============================================================
USE hanip_delivery02;
```
