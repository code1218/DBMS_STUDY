# Ch09 복습 퀴즈 (Ch10 시작 10분)

**Q1.** ERD의 `orders ||--o| reviews`를 바르게 읽은 것은?
- ① 주문 하나에 리뷰가 반드시 하나 있다
- ② 주문 하나에 리뷰가 0개 또는 1개 있다
- ③ 주문 하나에 리뷰가 여러 개 있을 수 있다
- ④ 리뷰 하나에 주문이 여러 개 있다
- ⑤ 리뷰 없이는 주문할 수 없다

**Q2.** 다음 테이블(PK = 학번 + 과목코드)에서 **2NF를 위반**하게 만드는 종속은?

| 학번 | 과목코드 | 학생이름 | 성적 |
|---|---|---|---|

- ① (학번, 과목코드) → 성적
- ② 학번 → 학생이름
- ③ 과목코드 → 과목코드
- ④ 성적 → 학번
- ⑤ 위반 없음

**Q3.** 주문 한 건을 지웠더니 그 가게의 전화번호까지 데이터에서 사라졌다. 이 현상의 이름은?

**Q4.** 다음 중 정규화 단계와 제거 대상의 짝이 **틀린** 것은?
- ① 1NF — 반복 그룹 / 한 칸의 여러 값
- ② 2NF — 부분 함수 종속
- ③ 3NF — 이행 함수 종속
- ④ BCNF — 결정자가 후보키가 아닌 종속
- ⑤ 3NF — 기본키 제거

**Q5.** `order_items.unit_price`가 `menus.price`와 별도로 있는 이유를 한 문장으로 쓰시오.

**Q6.** 릴레이션 수강(<u>학생</u>, <u>과목</u>, 교수)의 함수 종속이 (학생, 과목) → 교수, 교수 → 과목일 때, 이 릴레이션이 만족하는 **가장 높은 정규형**은?
- ① 1NF ② 2NF ③ 3NF ④ BCNF ⑤ 비정규형

**Q7.** 테이블 `T(a, b, c)`를 `T1(a, b)`, `T2(b, c)`로 나눈 뒤 `b`로 JOIN했더니 원래보다 행이 많아졌다. 이렇게 생긴 행을 무엇이라 부르고, 무손실 분해가 되려면 `b`가 어떤 조건을 만족해야 하는가?

<summary>정답</summary>

| 문항 | 정답 | 해설 |
|---|---|---|
| Q1 | ② | `o\|` = 0 또는 1. `uq_reviews_order` UNIQUE가 "최대 1"을 강제 |
| Q2 | ② | 학생이름이 PK의 **일부**(학번)에만 종속 → 부분 종속 |
| Q3 | 삭제 이상 | 가게 정보가 주문에 붙어서만 존재했기 때문 |
| Q4 | ⑤ | 정규화는 키를 없애는 과정이 아님 |
| Q5 | 메뉴 가격은 바뀌므로 **주문 시점의 판매가**를 보존해야 과거 매출·영수증이 변하지 않는다 | |
| Q6 | ③ | 후보키 (학생, 과목) · (학생, 교수) → 세 열 모두 주요 속성이라 3NF 만족. 결정자 '교수'가 후보키가 아니라 BCNF 위반 (수업 5-6절 `rider_assign`과 같은 모양) |
| Q7 | 가짜 튜플(spurious tuple) / `b`가 `T1` 또는 `T2`의 **키** | 공통 열이 어느 쪽에서도 키가 아니면 없던 조합이 생김 (실습 9번) |
